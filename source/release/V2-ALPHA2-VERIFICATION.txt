BSTY-FastSeed 2.0.0-alpha2 interopfix-r1 — 2026-10-30

Issue: phase13_interop_tests still asserted /BSTYFastSeed:0.1/ after alpha2
changed the advertised user agent to /BSTYFastSeed:2.0.0-alpha2/.
The old assertion was reproduced locally on the delivered alpha2 source.
Fix: include core/version.hpp in the test and derive its expected agent from
core::version. The test still checks the actual bytes decoded from the socket.
Runtime code and wire behavior are unchanged by this correction.
